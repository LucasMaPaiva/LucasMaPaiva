# Olá, eu sou o Lucas Paiva 👋

**Desenvolvedor Full Stack, backend e IA aplicada.** Laravel e PostgreSQL em produção, serviços em Go e aplicações com LLMs em Python (RAG, agentes, modelos locais). Em Boa Vista, Roraima, trabalhando remoto.

Gosto de **medir antes de afirmar**: cada projeto abaixo tem uma avaliação com casos de resposta conhecida, e os números estão aqui.

### Projetos em destaque

| Projeto | O que é | Resultado |
|---|---|---|
| **[rag-laravel-docs](https://github.com/LucasMaPaiva/rag-laravel-docs)** | RAG local sobre a documentação do Laravel, com busca vetorial e híbrida no PostgreSQL (pgvector + pg_trgm) | Acerto conceitual de **21% para 84%** com embeddings multilíngues e **90%** com a busca híbrida, em 30 perguntas em português sobre texto em inglês |
| **[agenda-bot](https://github.com/LucasMaPaiva/agenda-bot)** | Bot do Telegram que transforma "dentista amanhã às 9h" em evento no Google Agenda, com LLM local (Gemma 3 no Ollama) | **0 de 15** só com o modelo, **14 de 15** com datas e recorrências resolvidas em código |
| **[accounts-receivable](https://github.com/LucasMaPaiva/accounts-receivable)** | Microsserviço de contas a receber em Go, extraído de um monólito Laravel | Pagamento transacional, eventos no RabbitMQ com inbox idempotente e outbox, servidor MCP só leitura, métricas Prometheus e CI |

### O que eu uso

- **Backend:** PHP / Laravel, Go, Python (FastAPI), APIs REST, filas (RabbitMQ)
- **Banco de dados:** PostgreSQL (otimização de consultas, pg_trgm, pgvector, PL/pgSQL), Redis
- **IA aplicada:** RAG, LLMs locais com Ollama, saída estruturada em JSON, MCP, agentes, avaliação de modelos
- **Frontend:** Vue.js / Nuxt, React, TypeScript
- **Infra:** Docker, CI/CD, Prometheus, Linux
